# 🛠️ Multi-Utility Toolkit

## 📌 Project Overview

**Multi-Utility Toolkit** is a Python-based utility project that combines multiple useful operations into a single easy-to-use menu-driven application.

The project provides different utilities for **Date & Time, Mathematical Calculations, Random Data Generation, UUID Generation, and File Operations**.

It is designed to make different everyday utility tasks simple and organized through a single application. 🎯

---

## 🎯 Objectives

The main objectives of this project are:

* 🐍 Practice Python programming concepts
* 📦 Understand Python modules and packages
* 🔄 Create a menu-driven application
* 🧮 Perform different mathematical calculations
* 📅 Work with dates and time
* 🎲 Generate random data
* 🔐 Generate random passwords and OTPs
* 📁 Create, read, and append files
* 🆔 Generate unique identifiers
* 🔍 Explore module attributes using Python's `dir()` function

---

## ✨ Main Features

### 📅 1. Date & Time Operations

This module provides different operations related to date and time.

Features include:

* 🕐 Display current date and time
* 📆 Calculate the difference between two dates
* 🗓️ Display dates in different formats
* ⏱️ Stopwatch functionality
* ⏳ Countdown timer

The project uses Python's date and time functionality for these operations.

---

### 🧮 2. Mathematical Operations

The Mathematical Operations module provides several useful calculations.

Features include:

* 🔢 Factorial calculation
* 📐 Trigonometric calculations
* 📊 Logarithm calculation
* 💰 Compound interest calculation
* ⭕ Area of a circle

These operations use Python's mathematical functions through the `math` module.

---

### 🎲 3. Random Data Generation

The Random Operations module generates different types of random data.

Features include:

* 🎯 Random number generation
* 🔀 Shuffle a list
* 🔐 Random password generation
* 🔢 OTP generation
* 🎰 Random sampling

The module uses Python's random and string functionality to generate different outputs.

---

### 🆔 4. UUID Generation

The project also includes a **UUID Generation** option.

UUID stands for **Universally Unique Identifier**.

It is useful when a program needs a unique identifier for different objects, records, files, or resources.

---

### 📁 5. File Operations

The File Operations module allows users to work with text files.

Features include:

* 📄 Create a new file
* 📖 Read file content
* ➕ Append new data to an existing file
* ⚠️ Handle file-not-found situations

This module makes basic file handling easier through a simple menu.

---

## 🔍 6. Explore Module Attributes

The project includes an option to explore module attributes.

Users can view the available attributes and functions of Python's built-in `math` module and the custom `math_utils` module.

This feature helps in understanding how Python modules can be inspected using `dir()`.

---

## 🖥️ Main Menu

The application provides a central menu with the following options:

1. 📅 Date & Time Operations
2. 🧮 Mathematical Operations
3. 🎲 Random Data Generation
4. 🆔 UUID Generation
5. 📁 File Operations
6. 🔍 Explore Module Attributes
7. 🚪 Exit

This menu allows users to easily select the required utility.

---

## 📂 Project Structure

The project is organized into separate modules so that each utility has its own responsibility.

### 📄 Main Module

**main.py**

Acts as the central part of the application and connects all utility modules together.

### 📄 Date & Time Module

**datetime_utils.py**

Handles date and time related operations.

### 📄 Mathematical Module

**math_utils.py**

Handles mathematical calculations.

### 📄 Random Module

**random_utils.py**

Handles random numbers, passwords, OTPs, shuffling, and sampling.

### 📄 UUID Module

**uuid_utils.py**

Handles UUID generation.

### 📄 File Module

**file_utils.py**

Handles basic file operations.
